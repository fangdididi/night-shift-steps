# Replace the backup disk on the office NAS

You will need the new disk and about 30 minutes, and it is a good idea to tell people the shared drive will be unavailable.

1. Log in to the NAS admin page and go to Storage, then select Disk 2.
2. The disk should be marked as "Failing" by the system.
3. Power off the NAS if it is still running.
4. Pull out the tray for Disk 2 and put the new disk in it.
CAUTION: The old disk can be hot.
5. Power the box back on and make sure the rebuild starts properly.
